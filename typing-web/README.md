# Keyflow 打字练习

直接用浏览器打开 `dist/index.html` 即可游玩，无需安装依赖。

三档速度，每局 20 轮；支持实体键盘和屏幕键盘，显示实时倒计时、得分、准确率及连续正确次数。按 Esc 或点击“结束练习”退出，结束后可再次开始。

原 C++ 终端版保留在上级目录。浏览器版本使用 HTML、CSS 和 JavaScript。

内置普通话提示：开始练习、正确、再试一次、时间到了和最终得分。右上角可静音。使用浏览器 Speech Synthesis，优先选择 zh-CN 语音；设备需提供普通话语音，离线可用性取决于所选系统语音。快速输入会替换旧播报，避免积压。
